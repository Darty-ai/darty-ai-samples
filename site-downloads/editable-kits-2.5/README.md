# Darty-Ai editable sample kits

Download a ZIP, extract it, and open its Excel workbook in Darty-Ai. Each kit
contains **Assets**, **AI Templates** and **Excel Sheets**, plus a short
**START HERE.txt** guide. These are ready-to-use Illustrator samples.

Use Adobe Illustrator 2025 or newer with Darty-Ai 2.5. Fonts are listed in the
workbook's **Start here** worksheet; activate them or choose replacements before
exporting. Font files are not distributed with these samples.

## Generate your Illustrator files

1. Extract the complete ZIP to a local folder. Keep its three folders together.
2. In Illustrator, open Darty-Ai and choose **Data**.
3. Load the workbook from **Excel Sheets**. Choose **Darty Designs**, the first sheet.
4. Turn on **Preview** in the traverser table. Select a record or use the
   previous/next controls. The spreadsheet selects the matching template.
5. In Darty-Ai **Export**, select your records, choose Illustrator (`.ai`) and
   an output folder, then export. Save output separately from **AI Templates**.

Edit record values in Excel and reload the saved workbook to make your own
versions. Keep the first four header rows; records start on row five.

The kits work from the extracted folder, including folder names with spaces.
References are relative to the workbook. Sticker illustrations load from Assets into three tagged source placeholders
on the pasteboard, then the table anchors copies into its cells. Templates start with short placeholder text and empty image, table and code
targets. Each layout has at least three spreadsheet variations. Common settings
use row 3 defaults; enter values in records only when they differ. Frame text
replacement uses its implicit mode, so no repeated @ mode is needed.

Food packaging includes two empty box templates and 30 fruit/language records on
one Darty Designs sheet. The 250 × 170 × 85 mm box is the header default for
plums, apricots, nectarines and strawberries; cherry rows override it with the
200 × 136 × 68 mm box. Shared settings also use header defaults, with explicit
row values for exceptions. Fruit artwork loads from Assets when you preview a row. Team apparel
includes two neutral vector layouts with three variations each. The other examples reuse one template
per kit. Packaging is a nominal carton prototype; apparel is placement artwork.
Adapt both to the specifications supplied by your printer or manufacturer.

Brands, people, addresses and credentials are fictional examples. Packaging
nutrition uses USDA FoodData Central values for raw fruit per 100 g, with source
links in the workbook. Tables vary between 9, 10 and 11 rows. The EAN-13 numbers
are checksum-valid demonstration identifiers; assign production identifiers
before commercial use. QR payloads differ by fruit and language.
Photographic mockups illustrate the designs; the native Illustrator files are the
editable artwork. Original source files are retained by the maintainers.

## Review PDFs and mockups

Each PDF opens with a mockup page, followed by the current Illustrator artwork
variations. Apparel shows both layouts together. Packaging shows all five fruit
mockups, then plums in English, German and French and the other four fruits in
English. Its Excel workbook retains all 30 fruit/language combinations.

Packaging mockups use Darty-Ai Box Maker with registered artwork exported from
Illustrator. The box proportions and print placement come from the document.
Separate image-tool realism experiments are excluded from these PDFs.
The contact sheets are high-resolution PNG grids, compressed with Darty-Ai
optimizeBitmap. Their ten files total 6.83 MB.

## Compatibility checkpoint — October 14, 2026

The current checks use Darty-Ai native **2.5.0.6406** in Illustrator 2026 on macOS.
The 63 workbook records use 12 minimal templates. Native Preview checks cover
all 33 non-packaging records and the seven packaging editions shown in the PDF,
including both box sizes and all three nutrition row counts. Review pages retain
vector text and are checked against the spreadsheet text and table values.

This release contains sample files, not a plug-in installer. The Mac checks do
not qualify Windows or long-session stability. Earlier Preserve-metadata export
failures for Events and Property remain a separate native investigation; these
review PDFs were saved from temporary artwork copies without source metadata.
